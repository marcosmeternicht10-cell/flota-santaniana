1. La clave

La crea el administrador en Sistema → Integraciones → Conectar un sistema, eligiendo qué puede ver o cargar. Se muestra una sola vez: guardala en un lugar seguro. Se envía en cada pedido:

Authorization: Bearer ls_xxxxxxxxxxxxxxxxxxxx

(También se acepta X-API-Key: ls_….) Probala con:

curl -H "Authorization: Bearer $CLAVE" {{ base }}/api/v1/estado
{% for c, n, d in permisos %}{% endfor %}
PermisoQué habilitaCódigo
{{ n }}{{ d }}{{ c }}
Límite: {{ limite }} pedidos por minuto por clave. Cada respuesta trae X-RateLimit-Remaining. Si se pasa, vuelve 429 con Retry-After (segundos).

2. Cómo vienen las listas

Todas las listas vienen igual. Se piden de a {{ por_defecto }} (hasta {{ max_filas }} con limit). Para la página que sigue, usá el link siguiente tal cual viene; cuando es null, no hay más.

{
  "datos": [ … ],
  "total": 1342,
  "limit": 100,
  "offset": 0,
  "siguiente": "{{ base }}/api/v1/ots?limit=100&offset=100"
}

Agregá formato=csv a cualquier lista para recibirla como CSV. Las fechas van AAAA-MM-DD; dias=30 en vez de desde trae los últimos 30 días. El coche se busca por número interno o por chapa.

3. Leer datos

GET/api/v1/vehiculosflota

La flota con el km actual de cada coche. activos=todos incluye los dados de baja; coche=210 trae uno.

curl -H "Authorization: Bearer $CLAVE" "{{ base }}/api/v1/vehiculos"

GET/api/v1/otsots

Las órdenes de trabajo, cada una con sus items (trabajo, técnico, costo, estado) y el costo_total. Filtros: desde, hasta, dias, estado (abierta, en_proceso, cerrada), coche.

curl -H "Authorization: Bearer $CLAVE" \
  "{{ base }}/api/v1/ots?estado=cerrada&desde=2026-10-01&hasta=2026-10-31"

GET/api/v1/ots/<número>ots

Una OT sola, con sus ítems.

GET/api/v1/combustiblecombustible

Las cargas: litros, precio, total, odómetro, estación, chofer. Filtros: desde, hasta, dias, coche, origen (taller, corporativo, rendicion). Trae litros_total y monto_total de todo el filtro.

GET/api/v1/rendicionesrendiciones

Los servicios rendidos por los choferes de corporativos, con el monto. Filtros: desde, hasta, dias, cliente, chofer (usuario), liquidado (0 o 1). Trae monto_total.

GET/api/v1/pagosrendiciones

Los pagos de plus a los choferes, por semana. Filtros: desde, hasta, chofer.

GET/api/v1/trafico/<fecha>trafico

El tráfico del día tal como se publicó (la última versión): cada salida con corredor, hora, destino, coche y tripulantes. La fecha puede ser hoy o mañana. tipo=internacional para el internacional.

curl -H "Authorization: Bearer $CLAVE" "{{ base }}/api/v1/trafico/hoy"

GET/api/v1/asignacion/<fecha>trafico

La asignación de corporativos del día tal como se publicó: cada servicio con cliente, tramo, chofer y coche, y la lista de cambios respecto de la versión anterior.

GET/api/v1/costoscostos

Costos cargados por coche y mes. Filtros: desde y hasta como mes (2026-10), meses=6, tipo, coche.

GET/api/v1/agenciasagencias

Las agencias de venta con su código, contacto y estado. Filtros: codigo, estado.

4. Cargar datos

POST/api/v1/combustiblecombustible:escribir

Registra una carga (por ejemplo, desde el sistema del surtidor). Obligatorios: coche y litros. Si la misma carga llega dos veces (mismo coche, fecha, litros y odómetro), responde 409 con el id que ya existe, así un reintento no la duplica.

curl -X POST -H "Authorization: Bearer $CLAVE" -H "Content-Type: application/json" \
  -d '{"coche":"210","fecha":"2026-11-06","litros":180,"precio_litro":7350,
       "odometro":412300,"estacion":"Petropar Mcal. López","chofer":"Juan Pérez"}' \
  {{ base }}/api/v1/combustible

Opcionales: costo_total (si no viene, litros × precio), tanque_lleno (por defecto sí), emblema, lugar_carga, origen (taller o corporativo), cliente, observaciones.

POST/api/v1/kilometrajekm:escribir

Informa el km de un coche (por ejemplo, desde el GPS). No acepta un km menor al que ya tiene ni un salto de más de 5.000 km, salvo con "forzar": true.

curl -X POST -H "Authorization: Bearer $CLAVE" -H "Content-Type: application/json" \
  -d '{"coche":"210","km":412450}' {{ base }}/api/v1/kilometraje

5. Enviar cualquier dato (bandeja de entrada)

Para que la integración sea de ida y vuelta: el otro sistema envía cualquier dato a un solo link, con el permiso recibir. El tipo va en la ruta, en minúsculas: ventas, pasajeros, liquidaciones, agencias…

POST/api/v1/entrada/<tipo>recibir

curl -X POST -H "Authorization: Bearer $CLAVE" -H "Content-Type: application/json" \
  -d '{"registros":[
        {"id":"V-1001","coche":"210","fecha":"2026-11-06","pasajeros":38,"monto":4560000},
        {"id":"V-1002","coche":"305","fecha":"2026-11-06","pasajeros":12,"monto":1440000}]}' \
  {{ base }}/api/v1/entrada/ventas

El cuerpo puede ser un registro solo, una lista, {"registros": [...]} o un CSV (Content-Type: text/csv, con títulos en la primera fila). Hasta 1.000 registros por envío. Los nombres de los campos se normalizan ("Nº Interno" → nro_interno) y el coche se reconoce como coche, interno, bus o unidad.

TipoQué pasa al llegarCampos
combustibleSe registra la carga en el cochecoche, litros, fecha, precio_litro, odometro
kilometrajeSe actualiza el km del cochecoche, km
agenciasSe crea o actualiza la agenciacodigo, nombre, ciudad, telefono, email…
fallasEntra como pedido de OTcoche, descripcion, chofer, km
costosSe suma al costo del cochecoche, mes (AAAA-MM), tipo, concepto, monto
cualquier otroSe guarda tal cual y queda a la vista en el sistemalos que tenga

Sin duplicados: mandá en cada registro su identificador de tu sistema (id, id_externo o codigo). Si llega igual, se ignora (repetido); si llega cambiado, se actualiza. La respuesta dice qué pasó con cada uno, y es 207 si alguno tuvo problema (los demás entran igual):

{ "recibidos": 2, "aplicados": 0, "guardados": 2, "repetidos": 0, "revisar": 0, "errores": 0,
  "detalle": [ {"n": 0, "id_externo": "V-1001", "estado": "guardado"}, … ] }

GET/api/v1/entrada/<tipo>recibir

Lo que ya llegó de ese tipo, con su estado, para confirmar desde tu lado qué entró. Filtros: desde, estado.

6. Planillas que se actualizan solas

Para Excel, Google Sheets o Power BI no hace falta programar: en Sistema → Integraciones → Planilla se elige qué datos y se genera un link. Ese link devuelve un CSV siempre al día.

DóndeCómo
ExcelDatos → Obtener datos → Desde la Web → pegar el link. Después, Actualizar todo trae lo nuevo.
Google SheetsEn una celda: =IMPORTDATA("link"). Se actualiza solo cada hora.
Power BIObtener datos → Web → pegar el link.
El link es como una llave: quien lo tenga ve esos datos. Si se comparte con quien no corresponde, desactivalo en la pantalla y generá otro.

7. Avisos: el sistema te avisa a vos

En Sistema → Integraciones → Avisar a otro sistema se pega un link (de tu sistema, o de Make, Zapier, n8n) y se eligen los eventos. Cuando ocurre un evento, se envía un POST con JSON:

POST https://tu-sistema/recibir
Content-Type: application/json
X-Santaniana-Evento: ot.cerrada
X-Santaniana-Firma: sha256=5d1c…

{
  "evento": "ot.cerrada",
  "id": "9f2c…",              ← único por aviso, para no procesarlo dos veces
  "momento": "2026-11-06T18:40:00",
  "sistema": "La Santaniana",
  "datos": { …la OT con sus ítems, igual que en GET /api/v1/ots/<n>… }
}
EventoCuándoQué trae
ot.abiertaSe abre una OTLa OT con sus ítems
ot.cerradaSe cierra una OTLa OT completa, con técnicos y costo
falla.reportadaUn chofer reporta una fallaCoche, chofer, km y los problemas
combustible.cargadoSe registra una cargaIgual que una fila de /combustible
rendicion.cargadaUn chofer corporativo rindeIgual que una fila de /rendiciones
trafico.publicadoSe publica el tráfico (y cada vez que se vuelve a publicar con cambios)Igual que /trafico/<fecha>, con cambios
asignacion.publicadaSe publica la asignación de corporativosIgual que /asignacion/<fecha>, con cambios

Respondé con cualquier código 2xx. Si no contesta o da error, se reintenta a los 10 s y al minuto; con 30 fallas seguidas el aviso se pausa solo. Para comprobar que el aviso viene de acá, calculá el HMAC-SHA256 del cuerpo con el secreto del aviso y compará:

# Python
import hmac, hashlib
esperada = "sha256=" + hmac.new(SECRETO.encode(), cuerpo_crudo, hashlib.sha256).hexdigest()
valido = hmac.compare_digest(esperada, request.headers["X-Santaniana-Firma"])

8. Errores

Siempre con el mismo formato, y el mensaje en castellano:

{ "error": { "codigo": "sin_permiso", "mensaje": "Esta clave no tiene el permiso «Combustible» (combustible)." } }
Código HTTPQué pasó
400Un dato o filtro mal escrito (el mensaje dice cuál)
401Falta la clave, no existe o fue revocada
403La clave no tiene ese permiso
404No existe (la OT, el coche, el tráfico sin publicar)
409Ya estaba cargado, o el km no cierra
429Demasiados pedidos: esperá lo que dice Retry-After
